# Jules AI Landing Page

This is a modern landing page for an AI software engineering tool built with:

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Features
- Dark theme with gradient backgrounds
- Hero section with large headline
- Code preview panel with typing animations
- Feature cards with hover effects
- Fully responsive design

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Start development server:
   ```bash
   pnpm run dev
   ```

3. Build for production:
   ```bash
   pnpm run build
   ```
